## 工具与平台

### [P-007 · PowerShell 内联脚本的编码/引号陷阱](P-007-powershell-inline-encoding.md)
**严重度**：🟡 中 · **怎么发现的**：反复踩
超过 3 行的脚本写成文件再执行——内联省下的几秒会在引号地狱里加倍还回来。

### [P-008 · git 钩子的相对路径假设](P-008-git-hook-relative-path.md)
**严重度**：🟡 中 · **怎么发现的**：装完钩子一提交就炸
脚本的运行位置 ≠ 开发位置。钩子/CI/部署脚本都会被移到别处执行。

### [P-003 · electron_mirror 是环境变量不是 npm config](P-003-electron-mirror-env-not-config.md)
**严重度**：🟡 中 · **怎么发现的**：查 CI 失败日志
构建工具的镜像配置多数走环境变量而非包管理器配置。**而且这个错误挂了很久没人知道——没人看的地方会烂掉。**

### [P-004 · 内网 IP 正则误报（版本号 / SVG 路径）](P-004-private-ip-regex-false-positive.md)
**严重度**：🟡 中 · **怎么发现的**：本地先跑 CI
**误报比漏报更危险**——满屏假警报会让所有人忽略这道闸，那它就等于不存在。
